# data

이 폴더는 Git에 올리지 않는 로컬 데이터 작업 위치입니다.

- 실제 원본·라벨·추론·집계 데이터는 저장소에 추가하지 않습니다.
- 개인정보·식별정보가 포함될 수 있으므로 공유 위치와 접근 권한을 팀장이 확인합니다.
- `raw`, `preprocessed`, `tokenized`, `review` 같은 하위 폴더명은 현재 작업자의 데이터 확인과 실험 편의를 위한 로컬 구조입니다.
- 위 경로는 서비스 공통 전달 계약이 아니며 특정 폴더가 항상 존재해야 하는 것도 아닙니다.
- 서비스 코드가 특정 경로에 실제로 의존하게 되면 생산자·소비자와 전달 방식을 확인한 뒤 저장소 문서에서 별도로 확정합니다.
- 데이터 의미·상태·버전의 정본은 [docs/DATA_CONTRACT.md](../docs/DATA_CONTRACT.md)입니다.
- 전달 위치·파일 버전·덮어쓰기·Windows/Linux 공유 방식은 [Notion 결정 대기 및 적용 현황](https://app.notion.com/p/3a5d365a80b481319695f4e3579006ec)에서 결정합니다.
