# Implementation Plan: Oliview ChatA FastAPI 웹 서비스 완전 전환 및 Uvicorn 단일 엔트리포인트 일원화 (Cutover ChatA to FastAPI Web Service & Uvicorn Single Entrypoint)

**Branch**: `046-chata-fastapi-cutover` | **Date**: 2026-09-02 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/046-chata-fastapi-cutover/spec.md`

---

## Summary

본 피처는 Oliview ChatA의 기본 웹 서빙 엔진을 Streamlit에서 Uvicorn 기반 FastAPI(`bteam/Oliview_chatbot_a/main.py`, Port 8501)로 완전 전환(Cutover)합니다. 데스크탑 뷰포트에서는 기존 ChatA의 시각적 디자인(상단 2열 설정/예시 박스, 상태 표시기, 하단 입력바)을 100% 동일(Pixel-Identical)하게 계승하고, 모바일($\le 768\text{px}$) 환경에서는 3x2 카테고리 반응형 그리드, Safe-Area 인셋 및 참조 리뷰 바텀 시트 드로어를 제공합니다. 또한 Dockerfile 실행 명령을 `uvicorn main:app`으로 일원화하고 기존 Streamlit `app.py`를 `legacy_archive/`로 격리하여 코드베이스의 단일 진실 공급원(SSOT)을 확립합니다.

---

## Technical Context

**Language/Version**: Python 3.12, Vanilla HTML5 / CSS3 / ES6 JavaScript (No Node.js build overhead)  
**Primary Dependencies**: FastAPI, Uvicorn, Pydantic v2, httpx, sse-starlette, Redis, PyMySQL, ChromaDB  
**Storage**: Redis (Session History & L2/L3 Cache), ChromaDB (Vector Store), MySQL (`vw_chroma_review_sentences`)  
**Testing**: pytest (`pytest bteam/Oliview_chatbot_a/tests/test_fastapi_web_stream.py`)  
**Target Platform**: Linux (Ubuntu Docker Container) / Windows Local Dev  
**Project Type**: FastAPI Async Web Service + Static Client  
**Performance Goals**: First Token TTFT < 1.0s, Static Page Load < 0.5s, 0ms Zero-Search Immediate Return  
**Constraints**: Port 8501 reused for seamless Nginx reverse proxy compatibility, Zero Hardcoded Paths (Relative Paths Only)  
**Scale/Scope**: 5 key files modified/quarantined, 100% test coverage
