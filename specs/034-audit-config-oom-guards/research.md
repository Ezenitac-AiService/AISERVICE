## 1. 독립적 GPU 아키텍처 스펙 매트릭스 (Independent GPU Architecture Matrix)

CPU와 GPU 조합은 고정이 아니므로, 시스템은 **GPU 세대(Pascal $\rightarrow$ Blackwell)**와 **CPU 명령어 세트(AVX 유무)**를 런타임에 각각 독립적으로 실측하여 직교적(Orthogonal)으로 결합합니다.

```text
======================================================================================================================================================

======================================================================================================================================================
GTX 1070 (노말)       Pascal           SM 6.1     8 GB        없음 (None)    FP32 표준           ❌ 미지원        Q8_0 KV Cache   Qwen 3.5 2B @ 16K ~ 32K
GTX 1080 Ti          Pascal           SM 6.1     11 GB       없음 (None)    FP32 표준           ❌ 미지원        Q8_0 KV Cache   Qwen 3.5 4B @ 32K ~ 48K
RTX 2080 (노말)       Turing           SM 7.5     8 GB        1세대 텐서     FP16 네이티브       ⚠️ 생략권장      Q8_0 KV Cache   Qwen 3.5 2B @ 32K
```

## 2. 독립적 CPU 명령어 감지 및 런타임 최적화 규칙 (Independent CPU Capability Rules)

어떤 GPU와 조합되든 CPU의 명령어 지원 여부에 따라 독립적으로 최적화 정책이 발동합니다:

```text
======================================================================================================================================================
CPU 명령어 세트 분류     대표 CPU 예시                           CPU 가속 특성 및 최적화 규칙
======================================================================================================================================================
1. AVX 미지원 CPU        Intel Core i7 930 (1세대 Nehalem 등)    - AVX/AVX2 부재로 CPU 신경망 연산 시 극심한 지연 발생
                                                                 - 규칙: 100% GPU VRAM 상주 (-ngl 999) 강제, CPU BLAS 연산 원천 차단
------------------------------------------------------------------------------------------------------------------------------------------------------
2. AVX2 지원 CPU         Intel Core i7 7th~14th, Core Ultra 등   - AVX2 / FMA3 / PCIe 4.0/5.0 고속 지원
                                                                 - 규칙: 고속 토큰 직렬화 및 DMA 버퍼 전송 활성화
======================================================================================================================================================
```
