# 1. 프로젝트 생성 (pyproject.toml 생성)
uv init

# 2. 가상환경 생성
uv venv .venv

# 3. 패키지 설치 (pyproject.toml에 자동 기록됨)
uv add chromadb sentence-transformers pymysql python-dotenv torch
uv add langchain-chroma langchain-huggingface huggingface-hub pymysql python-dotenv torch
uv add langchain-chroma langchain-huggingface kiwipiepy rank-bm25 python-dotenv
uv add pydantic httpx
uv add openai httpx pydantic
uv add streamlit

아래 버전지정은 안해도됨
uv add "chromadb==1.5.9"
uv run python -c "import chromadb; print(chromadb.__version__)"


# [주의]
ChromaDB(HNSW)를 Windows에서 사용할 경우
프로젝트 경로에 한글(예: '2차 팀프로젝트')이 포함되어 있으면
HNSW 인덱스(header.bin, data_level0.bin 등)가 정상 생성되지 않아
'Error loading hnsw index'가 발생할 수 있었다.

영문 경로(예: C:\Projects\Oliview_Project)로 옮긴 후 정상 동작 확인.



| 파일명                       | 한 줄 설명                                     |
| ------------------------- | ------------------------------------------ |
| **01.build_chroma_db.py** | 문서를 임베딩하여 **ChromaDB를 구축**하는 파일            |
| **02.search_chroma.py**   | ChromaDB에서 **벡터 검색만 테스트**하는 파일             |
| **03.hybrid_search.py**   | **Chroma + BM25 검색 결과를 RRF로 결합**하는 파일      |
| **04.reranking.py**       | **Cross Encoder로 검색 결과를 관련성 순으로 재정렬**하는 파일 |
| **05.chatbot.py**         | 검색된 문서를 LLM에 전달하여 **최종 답변을 생성**하는 파일       |
| **06.app.py**             | 챗봇을 **웹(서비스)에서 실행**하는 파일                   |
